# LDU Matériel - projet de départ
1. Ouvrir le dossier contenant `pom.xml`.
2. Utiliser Java 21 ou plus récent.
3. Lancer la classe principale depuis l'IDE, ou `mvn spring-boot:run`.
4. Ouvrir http://localhost:8080.
5. Suivre le sujet PDF et compléter les commentaires `TODO`.

Ce projet stocke volontairement les données en mémoire : elles sont perdues au redémarrage.
